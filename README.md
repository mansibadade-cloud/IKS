# Bharat Gyan — source code recreation

This is a recreated static front-end project based on the publicly visible Bharat Gyan website at:
https://bharat-wisdom-atlas.lovable.app

Important:
- This is NOT the original Lovable project export or its exact source code.
- It recreates the visible structure, content themes, styling and navigation as a standalone HTML/CSS/JavaScript website.
- Replace Team Member 1–6 with the real names before submission.
- The hero background image uses an external image URL; an internet connection is needed for that image and Google Fonts.
- Open `index.html` in a browser to preview.
- Upload the files and folders in this project to a GitHub repository.
